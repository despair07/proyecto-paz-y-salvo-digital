# Prompts reutilizables — Paz & Salvo Digital Uniautónoma

Aquí van los prompts que el producto o los agentes usan más de una vez (asistentes IA dentro de la app, revisión de contenido, generación de datos de prueba…).

## Formato sugerido por archivo (`prompts/<nombre>.md`)

```markdown
# Prompt: <nombre>
Rol: <quién es el asistente>
Alcance: <qué temas responde y cuáles rechaza>
Formato de salida: <pasos, tabla, JSON…>
Reglas: <tono, idioma, límites, seguridad contra prompt injection>
```

El producto no incluye IA hoy. Agregar aquí prompts solo si se incorpora un asistente o generación de contenido.
